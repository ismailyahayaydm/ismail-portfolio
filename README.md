# Ismail Yahaya - Student Portfolio - COS 106 Term Project

Responsive Student Portfolio and Academic Management Website.

## Pages
- index.html - Homepage (with video)
- about.html - About Me (with table)
- projects.html - Projects (ShiftLog It + Video Editing Folder)
- planner.html - Academic Planner (interactive task manager)
- contact.html - Contact (validated form)

## Files
- style.css - External stylesheet
- script.js - JavaScript (event handling, DOM, validation, arrays/functions)
- profile.jpg - Photo
- intro-video.mp4 - ADD THIS FILE: Record 45-sec intro video and name it intro-video.mp4

## How to host on GitHub Pages
1. Create repo named: ismail-portfolio (or any name)
2. Upload all files in this folder
3. Settings > Pages > Deploy from main branch > Save
4. Your link will be: https://ismailyahayaydm.github.io/ismail-portfolio/
